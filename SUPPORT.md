# Support

Thanks for using Caedral. This is how to get help with **caedral** (Official TypeScript/JavaScript SDK for the Caedral API).

## Channels

| Channel | Link | Use for |
|---------|------|---------|
| Discord community (fastest) | https://discord.gg/3BS5ngRvfS | questions, integration help, product updates |
| Email | support@caedral.com | account/billing issues and private matters |
| Docs | https://caedral.com/docs | guides and API reference |
| API status | https://api.caedral.com/v1/status | live platform status |

## Service level

Support is **best-effort**: community reports are triaged when maintainers are
available and there is no guaranteed response time. For urgent production
incidents, ping the Discord server instead of waiting on a GitHub issue.

## Before opening an issue

1. Search existing issues in this repository.
2. Include your version, a minimal reproduction, and expected vs. actual behavior.
3. Never post API keys, tokens or customer data. If you leaked a credential, rotate it immediately.

## Security

Do **not** open public issues for vulnerabilities — see [SECURITY.md](SECURITY.md).
